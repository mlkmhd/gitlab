The following features are being delivered for GitLab 19.6.
These features are now available on GitLab.com.

## Notable contributor

We are excited to recognize [José](https://gitlab.com/jmrp), a Level 5 contributor,
as this month's [Notable Contributor](https://contributors.gitlab.com/notable-contributors)!

José systematically expanded fine-grained personal access token authorization
across the GitLab GraphQL API. Fine-grained tokens can now read data like blame,
CODEOWNERS validation, available deploy keys, and project security metrics.
